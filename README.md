# CHAEN POS v1.15

Order screen update for faster product selection.

- Large two-column tappable product tiles
- Product name + icon only on the selection screen
- Tap a tile to open Size / Quantity / Discount details
- Red quantity badge appears at the upper-right of each product icon when that product is already in the current order
- Badge totals the quantity across sizes/discount variants of the same product
- Current Order total and CHECKOUT remain visible above the product grid
- Existing ₱30 OFF rule remains 22oz only; Signature Matcha Latte and Churros are excluded
- Existing History edit/delete, Close Day, Expense, backdated orders, and English UI retained
